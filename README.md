# Online Food Ordering System SQL

## 1. Project Description
The Online Food Ordering System is a database project developed using MySQL. It manages restaurant details, food menu items, customers, orders, and payments.

## 2. Objectives
- Maintain restaurant information.
- Store food menu details.
- Manage customer orders.
- Track payment information.
- Generate restaurant sales reports.
- Display customer order history.
- Identify popular food items.

## 3. Technologies Used
- MySQL
- SQL

## 4. Database Tables
1. Restaurants
2. Menu
3. Customers
4. Orders
5. Payments

## 5. Project Files
- `project.sql.sql` — SQL queries.
- `Online Food Order System MySQL-Project.pdf` — Problem statement.

## 6. How to Run
1. Open MySQL Workbench.
2. Open the SQL project file.
3. Select your project database.
4. Execute the SQL statements.
